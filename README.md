ALMINGO S.L. – Página web corporativa (versión internacional)

Sitio web oficial de ALMINGO S.L., empresa especializada en desarrollo de software y aplicaciones para empresas y particulares. Esta web, publicada en inglés, es la carta de presentación de la compañía en el mercado internacional.

📖 Contexto del proyecto

Tras la incorporación de una nueva gerencia, ALMINGO S.L. ha iniciado una etapa de renovación:

Revisión y cambio de las configuraciones de los equipos informáticos.
Sustitución de las bases de datos utilizadas para la gestión interna.
Expansión internacional, lo que requiere una nueva página web en inglés.
Adopción de un sistema de control de versiones que integre a todo el equipo de desarrollo, como medida de precaución.

Pasados los primeros meses de adaptación a la nueva dinámica de trabajo, llega el primer encargo de la nueva etapa: un bingo colectivo sobre Sostenibilidad (ver más abajo).

🎯 Objetivos de la web
Presentar la empresa y sus servicios a clientes internacionales.
Mostrar el portfolio de proyectos, incluido el primer encargo de la nueva etapa.
Facilitar el contacto con el equipo comercial y técnico.
Transmitir una imagen moderna, profesional y comprometida con la innovación.

🚀 Instalación y uso

# 2. Entrar en la carpeta del proyecto
cd almingo-web

# 3. Abrir index.html en el navegador

No requiere instalación de dependencias: basta con abrir index.html en cualquier navegador moderno.

🔀 Control de versiones y trabajo en equipo

Todo el equipo de desarrollo trabaja sobre un repositorio Git compartido.

Flujo de trabajo recomendado:

La rama main contiene siempre la versión estable.
Cada tarea se desarrolla en su propia rama: feature/nombre-de-la-tarea.
Los cambios se integran en main mediante pull request revisada por otro miembro del equipo.

Convención de commits:

feat: añade sección de servicios
fix: corrige el menú en móvil
docs: actualiza el README
style: ajusta colores de la cabecera
