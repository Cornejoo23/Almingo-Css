What we work with

The tools behind our software

We do not use a single technology for everything. For each project we choose the language that fits best with what the client needs, how long the software has to last and who will maintain it. These are the five we work with the most.

Java

A general-purpose language used to build stable applications that run on almost any system. At Almingo it is our main language for business software: management tools, back ends and desktop applications. It is also the language of our collective bingo project, where many players connect to the same game at once.

JavaScript

We use it to add behaviour to the websites and web applications we deliver: forms that check the data before sending it, dynamic tables and dashboards where our clients can follow their orders or reports in real time.

Python

A readable language that lets us write solutions quickly. We use it for automation scripts, data processing and reports. For example, when a client sends us spreadsheets every week, we can build a small program that cleans the data and prepares the results automatically.

C++

A fast language that gives us control over the memory and the performance of the program. We choose it when speed matters: tools that process large amounts of data, programs that communicate with hardware or components that other applications need to call.

Android

The platform for our mobile apps. We design and develop Android applications for companies that want to give their customers or their own staff a tool in their pocket, and also for individual clients with an idea for an app. We take care of the whole process, from the first sketch to the publication in the store.
